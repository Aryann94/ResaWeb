Pour exploiter mon site en local, j'ai utilisé WAMP sur Windows :
Installer WAMP : 
Dans un premier temps j'ai téléchargez le programme d'installation de WAMP depuis le site officiel.
    Ensuite j'ai lancé le programme d'installation et j'ai suivi les instructions pour installer WAMP sur votre système.

Configuration de WAMP:
    J'ai ensuite ouvert wamp et j'ai accéder à l'explorateur de fichiers, puis je suis allez dans le répertoire où WAMP a été installé. Le chemain d'accés est :
    C:\wamp\www

    J'ai ensuite déposé tous vos fichiers de codes, de fonts et d'images dans le dossier www pour accéder au site en local.

Accéder à votre site en local
    Dans votre navigateur, j'ai ensuite entré l'URL suivante pour accéder à votre site web en local :

http://localhost/resaweb/index
http://localhost/phpmyadmin/
